traveller's request in the evidence.

Work through this in order, silently:
Step 1: List every candidate's id, name, price_per_night, rating, and amenities.
Step 2: For each one, assign a score between 0 and 1.
Step 3: Only after completing steps 1-2 for every candidate, write your final answer.

Do not include steps 1-3 in your output. Do not drop any candidate from the ranking.

Return valid JSON only, as a list of objects sorted best-to-worst, with no prose and no
markdown fences. Each object must include id, name, score, and reason, where score is a
