## RAG requirement correction (supersedes the deterministic-answer design below)

Sufficient scoped itinerary evidence now goes through the configured local Ollama
model before any final answer is returned. Exact trip/day retrieval, deterministic
cost calculation, and insufficient-context guards are retained. Citations and
confidence are server-derived, never taken from model-generated metadata.
Unavailable/invalid model responses return errors, with no deterministic fallback.

contracts 44 (10 MCP / 34 RAG), collector tests 5. This includes CI-style disabled
environment flags. Compilation and diff whitespace checks passed. New tests cover
prompt context, mocked final-model output, retrieval-owned metadata, no model call
for missing evidence, timeout/HTTP/JSON/empty-output failures and legacy dispatch.
