Application Name:
VoyageAI Budget Manager

Database Schema (expenses table):
- id (integer, primary key)
- trip_reference (text, required) - opaque trip identifier, not owned by this service
- expense (text, required)
- category (text, required)
- estimated_cost (real, required)
- actual_cost (real, optional)
- destination_id (integer, required) - opaque destination identifier, not owned by this service
- status (text: Planned, Paid, or Cancelled)
- created_at / updated_at (text, ISO timestamps)
